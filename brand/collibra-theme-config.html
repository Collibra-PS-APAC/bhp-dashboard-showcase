Components override Quick color select for the components listed, so set them here when you want exact control. Anything not listed inherits the Quick color select values above. The primary button is a solid orange fill that brightens on hover and active, since #E65400 is the darkest shade. The secondary button is a teal outline: transparent at rest with teal outline and text, a light-teal fill on hover, and a deep-teal #083F45 fill with white text when pressed. Field labels follow the live the test instance UI (Collibra 2026.05) and may shift slightly in later releases.
